# NetWatch

Монитор сетевой активности Windows: в реальном времени показывает, какие программы куда обращаются и сколько трафика тратят.

## Возможности

- Учёт входящего и исходящего трафика по каждому процессу (TCP/UDP, IPv4/IPv6) через ETW.
- Определение доменного имени по IP: кэш DNS (WMI `MSFT_DNSClientCache`) + reverse DNS. Если имя неизвестно — показывается IP.
- Столбцы: Активность, Программа, Адрес (домен/IP), IP, Входящий, Исходящий, Всего.
- Сортировка по любому столбцу; по умолчанию — по времени активности (свежие сверху), с живой сортировкой.
- Подсветка строк, где передача идёт прямо сейчас (светло-зелёный).
- Системные процессы выделены фиолетовым.
- Поиск/фильтр по программе, домену или IP.
- Кнопки: Старт, Стоп, Пауза, Сброс.
- Контекстное меню по правому клику: «Перейти к расположению» — открывает Проводник с выделенным exe-файлом процесса.

## Требования

- Windows 10/11 x64.
- .NET 9 SDK — для сборки; .NET 9 Desktop Runtime — для запуска готового exe.
- Права администратора (нужны для kernel ETW).

## Сборка и запуск

Быстрый способ — запустить `build-and-run.bat`: батник запросит права администратора, пересоберёт проект и запустит его.

Вручную:

```
dotnet publish NetWatch.csproj -c Release -r win-x64 --self-contained false ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Готовый файл: `publish\NetWatch.exe`.

Если программа запущена без прав администратора, нажмите «Старт» — она перезапустится с повышением прав (UAC).

## Как это работает

- `Microsoft.Diagnostics.Tracing.TraceEvent` и провайдер `Microsoft-Windows-Kernel-Network` дают события TcpIp/UdpIp Send/Recv с `ProcessID`, размером и адресом назначения.
- Статистика агрегируется по паре «процесс + удалённый IP».
- Домены подтягиваются из кэша DNS через WMI каждые 5 секунд; для неизвестных IP выполняется reverse DNS.
- «Сброс» очищает накопленные счётчики, сбор при этом продолжается.

## Ограничения

- Требуются права администратора.
- DoH/DoT и общие IP CDN могут отображаться как IP, а не домен.
- Трафик через VPN/прокси учитывается на клиенте VPN/прокси, а не на исходном приложении.
- Loopback-трафик исключён.
- Один процесс может занимать несколько строк — по одной на удалённый IP.

## Структура проекта

```
Etw/NetworkCollector.cs      сбор событий ETW
Services/StatsStore.cs       потокобезопасная агрегация и сброс
Services/DnsResolver.cs      IP -> домен (DNS-кэш + reverse DNS)
Services/ProcessResolver.cs  PID -> имя процесса и путь к exe
Models/RemoteSnapshot.cs     снимок статистики
ViewModels/                  MVVM: главная модель, строки таблицы, команды
Helpers/                     форматирование байтов, список системных процессов
MainWindow.xaml/.cs          интерфейс
build-and-run.bat            пересборка и запуск
```
